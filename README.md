# 🎮 Conway's Game of Life - 창발 실험 시뮬레이터

Conway의 Game of Life를 직접 구현하고 다양한 규칙으로 실험할 수 있는 인터랙티브 시뮬레이터입니다.

## 🚀 빠른 시작

1. `index.html` 파일을 웹 브라우저에서 열기
2. 캔버스를 클릭하여 셀을 활성화
3. "시작" 버튼을 눌러 시뮬레이션 시작!

## ✨ 주요 기능

### 기본 컨트롤
- **시작/정지**: 시뮬레이션 실행 제어
- **한 스텝**: 한 세대씩 천천히 관찰
- **초기화**: 모든 셀 제거
- **랜덤 생성**: 무작위 초기 상태 생성

### 시각화
- 실시간 세대(Generation) 카운터
- 살아있는 셀 개수 추적
- FPS 표시
- 그라디언트 셀 렌더링

### 인터랙티브 기능
- 마우스로 클릭/드래그하여 셀 그리기
- 속도 조절 (1-60 FPS)
- 셀 크기 조절 (5-20px)

### 프리셋 패턴
다양한 흥미로운 패턴들이 포함되어 있습니다:

1. **Glider (활공기)** - 대각선으로 움직이는 작은 패턴
2. **Blinker (깜빡이)** - 2주기 진동자
3. **Toad (두꺼비)** - 2주기 진동자
4. **Beacon (등대)** - 2주기 진동자
5. **Pulsar** - 3주기 진동자
6. **Glider Gun** - 주기적으로 Glider를 생성하는 패턴
7. **Pentadecathlon** - 15주기 진동자
8. **R-pentomino** - 카오틱한 진화를 보이는 패턴 (1103세대 후 안정)
9. **Acorn (도토리)** - 작지만 5206세대까지 진화하는 패턴

## 🔬 창발(Emergence) 실험

### 규칙 커스터마이징
Game of Life의 규칙을 변경하여 다양한 창발 현상을 실험할 수 있습니다!

**표준 Conway 규칙 (B3/S23)**
- Birth (탄생): 3
- Survive (생존): 2,3

**실험해볼 만한 규칙들:**

1. **Day & Night (B3678/S34678)**
   - 탄생: 3,6,7,8
   - 생존: 3,4,6,7,8
   - 특징: 대칭적인 패턴, 빈 공간도 "살아있는" 것처럼 작동

2. **HighLife (B36/S23)**
   - 탄생: 3,6
   - 생존: 2,3
   - 특징: Replicator 패턴이 등장 (자기복제)

3. **Seeds (B2/S)**
   - 탄생: 2
   - 생존: (없음)
   - 특징: 모든 셀이 1세대만 살고 죽음, 폭발적 성장

4. **Life without Death (B3/S012345678)**
   - 탄생: 3
   - 생존: 0,1,2,3,4,5,6,7,8
   - 특징: 한번 태어난 셀은 절대 죽지 않음

5. **Maze (B3/S12345)**
   - 탄생: 3
   - 생존: 1,2,3,4,5
   - 특징: 미로같은 패턴 생성

6. **Coral (B3/S45678)**
   - 탄생: 3
   - 생존: 4,5,6,7,8
   - 특징: 산호초같은 성장 패턴

## 🎯 창발 현상이란?

창발(Emergence)은 간단한 규칙들의 상호작용으로부터 예측하기 어려운 복잡한 패턴이나 행동이 나타나는 현상입니다.

Game of Life에서 볼 수 있는 창발 현상:
- **Glider**: 단순한 규칙에서 "움직이는" 패턴이 출현
- **Self-replication**: 자기복제하는 패턴
- **Chaos to Order**: R-pentomino처럼 무작위로 보이다가 안정화
- **Infinite Growth**: Glider Gun처럼 영원히 성장하는 패턴

## 💡 실험 아이디어

1. **패턴 충돌 실험**
   - 여러 Glider를 서로 다른 방향으로 배치
   - 충돌 시 어떤 패턴이 나타나는지 관찰

2. **규칙 변경 실험**
   - 다른 B/S 규칙으로 같은 초기 패턴이 어떻게 진화하는지 비교
   - 안정적인 규칙 vs 폭발적인 규칙 비교

3. **밀도 실험**
   - 랜덤 생성으로 초기 밀도를 다르게 설정
   - 어떤 밀도가 가장 오래 살아남는지 관찰

4. **대칭 패턴 실험**
   - 완벽하게 대칭인 패턴을 만들고 진화 관찰
   - 대칭이 깨지는 순간과 그 이유 분석
